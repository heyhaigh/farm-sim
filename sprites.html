PROPAGATE · SPRITE LIBRARY

A review catalog of every character sprite sheet the game draws from — think a tiny Storybook for pixel people. Each tile loops one animation so the team can eyeball every character's every move and spot cycles that need updating. Sheets are 64px-cell grids: 4 rows = directions (the game maps down: row 0, side: row 2, up: row 3; row 1 is the second diagonal/unused row), N columns = frames (auto-detected from sheet width). Loaded live from assets/… — pure asset gallery, no game engine.
