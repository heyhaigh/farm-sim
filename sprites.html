PROPAGATE · SPRITE LIBRARY

A review catalog of every character and creature sprite the game draws from — think a tiny Storybook for pixel people. Each tile loops one animation so the team can eyeball every move and spot cycles that need updating. Character sheets are 64px-cell grids: 4 rows = directions (the game maps down: row 0, side: row 2, up: row 3; row 1 is the second diagonal/unused row), N columns = frames (auto-detected from sheet width). Creature tiles reuse the game's own crops and cycles (and import the real procedural builders from pixel.js for pond life). The Direction control only applies to character sheets — creatures render their fixed in-game row.
